# Plan: finishing M1.5 — build the approved design

The owner approved the designs on 2026-11-17 (T-152, Q-20) and named the product Frameforge
(D-031). This plan covers what is left of M1.5: the component library, the new app shell, the
rebuilt create flow, and the browser review. Nothing here calls fal.ai or Razorpay; every test
runs in mock mode. All work is on `development`.

The designs to build from are in [design/](design/); the rules are in [UX.md](UX.md).

## Proactive discovery

Checked on 2026-11-17 by reading the designs, the code and the task list.

## What runs in parallel

Phase 2 is three agents at once, each in its own worktree with files nobody else touches:
T-153b (`components/form/`), T-153c (`components/feedback/`, `components/layout/`) and T-157
(`backend/`). Phases 1, 3, 4 and 5 are serial because each builds on the one before. Fable merges
one branch at a time and runs the mock checks after each merge.

## Phase 5 results (2026-11-17)

Run in Chromium (Playwright 1.65.1, scratchpad only) against the real app: backend with
`AVATAR_PROVIDER=mock`, confirmed by `/api/v1/config` returning `"provider":"mock"` and the badge on
every screen. Widths 1440, 900, 390 and 360 px. No paid call was made.

| Check | Result |
| --- | --- |
| Full flow: details → voice → approve → progress → video → "Create another" | Works at 1440 and 390 px |
| Reload at review and during progress | Resumes the same job and address |
| Sideways scroll | None on any screen at 1440, 900, 390 or 360 px |
| One `h1`, one `main` per screen | Yes, including not-found |
| Navigation per width | Sidebar ≥1024, icon rail at 900, bottom bar at 390 and 360; only Create shown, marked current |
| Keyboard | First Tab is "Skip to content"; order: Create, photo, language, script, submit; focus visible on each |
| Empty submit | Both messages under their fields; focus moves to the photo |
| External requests | None (fonts bundled, D-032) |
| Console errors | None |
| Contrast of every token text pair | All ≥ 4.5:1 (lowest: muted text on page, 4.76) |

Fixed during the review (commit 522921f): the result video grew to the photo's height (now a
16:9 frame, as designed); sections lacked the designed cards; the drop zone showed no keyboard
focus ring.

Differences from the design that remain, by decision:

| Difference | Why |
| --- | --- |
| No price, credits, balance, banners step, script picker, consent checkbox, "Videos" links | Their features arrive in M2 to M5 (finding 1) |
| Page title sits under the testing notice, not in the top bar | The top bar carries the mock badge; the internal-testing notice must stay visible |
| Native audio and video controls instead of the drawn players | Accessible by default; a custom player is optional polish |
| Stepper stays on "Video" as current when the video is ready | The design marks all done; the compact phone label needs a current step |

Gate B (2026-11-17): `npm run check` 26 files, 240 tests passed; build passes. Backend: ruff, format,
mypy and 70 tests pass. Three untracked files from 16 Nov (`backend/app/config.py`, `db.py`,
