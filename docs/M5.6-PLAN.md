## Context

Today the customer cannot choose a voice; it is fixed per language in settings. The owner wants,
between choosing the photo and making the voice:

1. a gender dropdown (male / female),
2. a voice dropdown with 4–5 ready-made voices of that gender,
3. a play button to hear the selected voice on a sample text,
4. then either use that voice, or record their own voice with a mic.

Scope: backend only, plus designs on the canvas. No frontend feature code.

| Release | Contents | When |
| --- | --- | --- |
| A (this milestone) | Preset voices, sample playback, spoken-script recording, full design including the cloning screens | Now |
| B (deferred, D-075) | Cloning: "My voices" (up to 3), 150 credits each, lock-in call, staff command | Only after the owner-run clone test passes |

### Table columns (`jobs`, one migration, T-572)

`voice_kind` Text NULL (`preset`, `spoken`; NULL = today's default voice), `voice_preset_id` Text
NULL, `voice_consent_version` Text NULL, `voice_consent_at` timestamptz NULL.

### Provider (`backend/app/providers.py`, T-576)

`async def synthesize_speech(self, text: str, language: str, preset_voice: str | None = None) -> Speech`

- `preset_voice=None`: the request sent is exactly today's, for every language.
- `preset_voice` set (a `provider_voice` value): fal sends `gemini_model` with
  `{prompt: text, voice: preset_voice, language_code: preset_language_codes[language], output_format: "wav"}`.
- Mock: a tone whose pitch depends on `preset_voice`, same length rule as today.

### Recording intake (`backend/app/media/recording.py`, T-573)

`async def prepare_recording(data: bytes, *, min_seconds: float, max_seconds: float, max_bytes: int) -> PreparedRecording`

- `PreparedRecording(data: bytes, extension: str, duration_seconds: float)`; output is WAV, mono,
  24 kHz, 16-bit (no codec dependency; 60 s is under 3 MB).
- Raises `RecordingError(code, message)` with code `recording_too_large`, `recording_not_audio`,
  `recording_too_short` or `recording_too_long`. Messages are plain words and say what to do.
- ffprobe and ffmpeg are called with argument lists, never a shell string.

### Routes and error codes (T-571 writes the stubs)

| Route | Behaviour |
| --- | --- |
| `GET /api/v1/config` | Adds `voice_options`: `{presets: [{id, name, gender, languages, sample_languages}], sample_texts: {language: sentence}, spoken: {languages, consent_text, consent_version, max_seconds}}` |
| `GET /api/v1/voice-presets/{preset_id}/sample?language=` | Login required. The stored clip, or 404 `voice_not_available` (unknown preset or language) or 404 `sample_not_found` (clip not made yet). Never calls the provider |
| `POST /api/v1/jobs` | New optional form fields `voice_kind`, `voice_preset_id`, `voice_recording` (file), `voice_consent`, `voice_consent_version` |

`POST /jobs` rules, checked after the existing 401/403/402 and photo-consent checks:

| Case | Result |
| --- | --- |
| No `voice_kind` | Today's behaviour, unchanged |
| `voice_kind=preset` with a valid `voice_preset_id` | Voice made with that preset; 10 credits as today |
| `preset` with a missing, unknown or not-offered id | 422 `voice_not_available`, field `voice_preset_id` |
| `voice_kind=spoken`, language in `spoken_languages` | Needs `voice_recording`, `voice_consent=true` and the current `voice_consent_version`; otherwise 422 `voice_consent_required` or `voice_consent_outdated` (field `voice_consent`), or a `RecordingError` code as 422 (field `voice_recording`). All checks and the transcode happen before anything is charged or stored |
| `spoken` accepted | 10 credits and the job row commit together; the job starts at `audio_ready` with the recording as its audio and the video price from its measured length |
| `spoken` with a language not in `spoken_languages` | 422 `voice_not_available`, field `voice_kind` |
| `voice_kind=my_voice` | 501 `not_implemented` (Release B) |
| Any other `voice_kind`, or `voice_kind` together with `voice_from_job_id` | 422 `validation_error`, field `voice_kind` |

`JobOut` gains `voice_kind` and `voice_preset_id`.

### Samples (`backend/app/voice_presets/`, T-579)

- File name: `<voice_samples_dir>/<preset id>/<language>.wav`.
- Command: `uv run python -m app.voice_presets.make_samples`. It makes each missing clip with one
  `synthesize_speech(sample text, language, preset_voice)` call and skips clips that exist, so a
  second run makes none. In mock mode it costs nothing. It refuses to run with the fal provider
  unless `--confirm-paid-run` is given (D-076).
